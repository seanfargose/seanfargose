# Sean Fargose GitHub Profile

This repository is designed to be uploaded directly to `seanfargose/seanfargose`.

## Upload

1. Extract this ZIP.
2. Upload the contents to the `main` branch of your `seanfargose/seanfargose` repository.
3. Go to **Settings → Actions → General → Workflow permissions**.
4. Select **Read and write permissions** and save.
5. Go to **Actions → Generate GitHub Stats → Run workflow**.
6. Go to **Actions → Generate Contribution Snake → Run workflow**.

The stats workflow creates:

- `profile/stats-dark.svg`
- `profile/stats-light.svg`
- `profile/top-langs-dark.svg`
- `profile/top-langs-light.svg`

The snake workflow publishes:

- `github-contribution-grid-snake.svg`
- `github-contribution-grid-snake-dark.svg`

to the `output` branch.

The README uses `<picture>` elements so GitHub viewers automatically see the appropriate light/dark assets.

## Important

The `profile/` directory contains `.gitkeep` before the first stats workflow run. The four real stats SVGs are generated by GitHub Actions and committed after the workflow succeeds.

The snake files are intentionally published to the separate `output` branch by the snake workflow.

## Files

- `README.md` — profile page
- `assets/dark_mode.svg` — dark profile artwork
- `assets/light_mode.svg` — light profile artwork
- `.github/workflows/stats.yml` — stats generator
- `.github/workflows/snake.yml` — contribution snake generator
